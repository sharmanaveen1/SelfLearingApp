## 🚀 Getting Started

### 📦 1. Install Dependencies

Make sure you have:

- Node.js  
- npm or yarn  
- Android Studio  
- Xcode (Mac only for iOS)  

```bash
npm install
```

---

### ▶️ Start Metro Server

```bash
npm start
# OR
yarn start
```

---

## 📱 Run the App

### 🤖 Android

```bash
npm run android
# OR
yarn android
```

---

### 🌍 Environment-based Builds

```bash
npm run android:dev
npm run android:staging
npm run android:prod
```

---

### 🍏 iOS (Mac Only)

Install CocoaPods dependencies:

```bash
bundle install
bundle exec pod install
```

Run the app:

```bash
npm run ios
# OR
yarn ios
```

---

## 📦 Build APK / AAB

### Generate APK

```bash
cd android
./gradlew assembleRelease
```

### Generate AAB

```bash
./gradlew bundleRelease
```
